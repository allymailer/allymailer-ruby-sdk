# AGENTS.md

AllyMailer Ruby SDK — client for the AllyMailer transactional email Web API (Web API 1.90).

## Working on this repository

- **Generated code.** The whole package is generated by the AllyMailer team from the AllyMailer Web API OpenAPI spec (Web API 1.90): sources, docs, README.md and this file. Do not hand-edit it: the next release replaces the content of this repository. Report problems and requests in the issues of this repository (https://github.com/allymailer/allymailer-ruby-sdk).
- **Build and check:**

  ```bash
  gem build *.gemspec
  ```

- **Source label.** Every request carries the query parameter `platform=ruby-sdk.1.1.1`, added in one place, the shared request client (`ApiClient`); a package built on this SDK puts its own label in front: `<package>.<version>,ruby-sdk.1.1.1`.
- **Tests.** Before a release the generator builds and lints the package and runs every example of docs/ and of this file against a mock of the API: no real API key, no real sends.
- **Release.** The version (1.1.1 in the gemspec) and the tag `v1.1.1` come from the generator; README.md states the Web API version the release was generated from.
- **Secrets.** Never commit API keys; the examples read `ALLYMAILER_API_KEY` from the environment.

## Integrating AllyMailer with this SDK

Full quickstart: [README.md](README.md). Install:

```bash
gem install allymailer-ruby-sdk
```

Requirements: Ruby 2.7+.

If the project is built on one of these frameworks, install its package instead: it brings this SDK and plugs it into the framework (configuration, client in the container, mailer, webhooks).

| Framework | Package | Guide |
|---|---|---|
| Ruby on Rails | `allymailer-rails` | [AGENTS.md](https://github.com/allymailer/allymailer-rails/blob/HEAD/AGENTS.md) |

Rules that generated code must follow:

- Server-side only. Read the API key from `ALLYMAILER_API_KEY`; never put it in browser or mobile code, never commit it.
- Base URL `https://cp.allymailer.com/ua/transactional/api/v1`; every method is POST with a JSON body; auth header `X-API-KEY`. The SDK does all of it.
- First email without DNS: `domain/get-sandbox-domain` → `confirmed-email/create` (the user clicks the link within 48 hours) → `email/send` from `noreply@<sandbox-domain>` to the confirmed address. Account API key only; up to 10 confirmed addresses, 100 emails a day; the domain expires after 31 days.
- Never ship a sandbox domain as the production sender (it is not in `domain/list`); read `from_email` from config. Production needs a verified domain: `domain/get-dns-records` → DNS records → `domain/validate-verification-record`, `domain/validate-dkim` → `domain/list`.
- Set `message.idempotence_key` on retryable sends; retry network errors, `429` and `5xx` with backoff, not other errors unchanged. Up to 500 recipients and 10 MB per request with the attachments in base64 (a third larger than the files); always `body.html` or `body.plaintext`.
- Delivery events via webhook (`webhook/set`) with a fast, idempotent HTTPS handler, not polling; check the `auth` field of every notification: the MD5 of the request body with the `auth` value replaced by the API key.
- Keep the default unsubscribe and tracking behaviour; changes go through AllyMailer support.
- Do not invent methods or fields. Check [docs/](docs/) of this package, the [API reference](https://docs.allymailer.com.ua/ua/web-api-ref) or [llms.txt](https://docs.allymailer.com.ua/llms.txt).

### Send an email

The client reads the API key from `ALLYMAILER_API_KEY`:

```ruby
require 'allymailer'

Common = AllyMailer::Common::Model
Email = AllyMailer::Api::Email::Model

client = AllyMailer.client(ENV.fetch('ALLYMAILER_API_KEY'))

response = client.email.send_email(Email::EmailSendRequest.new(
  message: Email::MessageObject.new(
    recipients: [
      Email::MessageObjectRecipientsItem.new(
        email: 'user@example.com',
        substitutions: {
          'CustomerId' => '12452',
          'to_name' => 'John Smith',
        }
      )
    ],
    body: Common::BodyObject.new(
      html: '<b>Hello, {{to_name}}</b>',
      plaintext: 'Hello, {{to_name}}'
    ),
    subject: 'AllyMailer test email ',
    from_email: 'email@example.com',
    from_name: 'John Smith'
  )
))
p response.job_id
```

### Errors

Every method throws `ApiError` when the request fails: the HTTP status (0 for a network error or a timeout), the [API error code](https://docs.allymailer.com.ua/ua/web-api-ref#api-errors) and the message.

```ruby
# client created as above
begin
  client.system.ping
rescue AllyMailer::Client::ApiError => e
  # http_status is 0 for a network error or a timeout
  warn "#{e.http_status} #{e.error_code} #{e.message}"
end
```
